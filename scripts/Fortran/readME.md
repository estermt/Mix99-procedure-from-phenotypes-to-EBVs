The `.f90` file must be compiled before execution.  
It converts original alphanumeric IDs into numeric IDs.

## Input files and parameters

- Genotype file containing the original IDs
- `.inbr` file generated by Relax2 in the previous step. This file contains both the original and renumbered IDs.
- Output filename for the recoded genotype file
- Number of markers
- Number of characters in the original ID in file 1
- Number of characters in the original ID in file 2
- Number of characters in the renumbered ID in file 2
